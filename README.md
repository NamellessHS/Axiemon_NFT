# Axiemon NFT 🐉✨

A decentralized 3D MMORPG built with **Unity** and integrated with the **Ronin Network** ecosystem.

![Axiemon Logo](https://raw.githubusercontent.com/NamellessHS/Axiemon_NFT/main/axiemon_nft_logo.png) *(Note: Replace with actual URL after push)*

## 🎮 About the Project
**Axiemon NFT** is a turn-based strategic RPG where players can bring their own Axie Infinity collections into a vibrant 3D world. Explore vast landscapes, engage in strategic combat, and interact with the blockchain in a seamless gaming experience.

## 🚀 Current Status: Phase 1 Complete
- [x] **Unity URP Foundation**: High-performance 3D rendering setup.
- [x] **Sky Mavis GraphQL Integration**: Real-time fetching of Axie NFT data, parts, and attributes via API Gateway.
- [x] **Dynamic Collection UI**: Automatic generation of Axie cards with real-time image loading from the Sky Mavis CDN.

## 🛠️ Tech Stack
- **Engine**: Unity 6 (Universal Render Pipeline)
- **Language**: C#
- **Blockchain**: Ronin Network
- **API**: Sky Mavis GraphQL (Marketplace & Partner API)
- **UI**: TextMeshPro & Modern uGUI

## 📦 Features
- **Wallet Integration**: Fetch any Ronin wallet's Axie collection instantly.
- **Data Mapping**: Automatic parsing of Axie parts (Eyes, Ears, Mouth, Horn, Back, Tail) for gameplay stats.
- **Web-to-Game Assets**: Dynamic loading of 2D/3D representations based on NFT metadata.

## 🛠️ Installation & Setup
1. Clone the repository.
2. Open with Unity 6.0+.
3. In `AxieGraphQLClient.cs`, insert your **Sky Mavis API Key**.
4. Run the `SampleScene` to test collection fetching.
